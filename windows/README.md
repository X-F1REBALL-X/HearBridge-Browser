# HearBridge Browser for Windows

Portable `.exe` (Go + github.com/jchv/go-webview2, no CGO) that opens a native
window "HearBridge Browser 1.0.0" with Edge WebView2 and loads
`http://<console-ip>:8096/` (default 192.168.50.10).

- Probes `http://<ip>:8096/status` first (4 s timeout). On failure shows a page
  with a Console IP box + Retry. Last working IP saved in
  `%APPDATA%\HearBridge Browser\settings.json` (`{"consoleIp": "..."}`).
- WebView2 user data: `%LOCALAPPDATA%\HearBridge Browser\WebView2`.
- Autoplay: `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--autoplay-policy=no-user-gesture-required`.
- WebView2Loader.dll is embedded in the exe (loaded from memory) - no DLLs needed.
- Needs the Microsoft Edge WebView2 Runtime (built into Windows 11 and current
  Windows 10); otherwise an error box explains where to get it.

Build (needs Go 1.24+, `go-winres` is installed by the script if missing):
`./build.sh` -> `dist/HearBridge-Browser-1.0.0-windows-x64.exe`.
The `.syso` resource file is generated by the build and not committed.
Icon: `assets/icon.ico` (16-256 px) made from `../docs/icon-1024.png`.
